# COOL
The official code repository for COOL (Comprehensive knOwledge enhanced prOmpt Learning for domain adaptive few-shot fake news detection))
DASFAA 2025 paper: https://dl.acm.org/doi/abs/10.1007/978-981-95-4158-4_2

## Environment Requirement

python: 3.9.19

torch: 2.2.2+cu121

numpy: 1.22.4

transformers: 4.39.3

## Run

To run the code:

```
python run_few_shot.py
```
